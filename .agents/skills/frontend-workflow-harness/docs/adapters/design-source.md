# 디자인 원본 어댑터

디자인 URL, 파일·페이지·node, 확인한 버전과 기존 UI 경로를 기록한다. 디자인 원본과 실제 서비스의 차이가 있으면 이번 기능의 기준을 정한다.

Figma 연결 도구가 있으면 파일 접근을 먼저 확인하고 관련 컨텍스트·이미지·변수를 읽는다. 해당 도구의 스킬을 사용할 수 있는 환경에서는 그 지침을 따른다. 파일에 접근할 수 없으면 사용자에게 필요한 원본을 요청하고 의존하는 픽셀 작업을 가정으로 표시한다.

기능 구현 요청만으로 Figma 원본을 편집하지 않는다. 반대로 Figma 편집 요청만으로 앱을 배포하지 않는다. 서로 다른 산출물이다.

토큰·컴포넌트는 실제 구현과 연결해 재사용한다. 새로운 공통 컴포넌트는 여러 실제 사용처와 변형이 확인될 때 분리한다. 한 화면을 위해 거대한 디자인 시스템 재설계를 시작하지 않는다.

시각 검증은 원본 viewport, 간격·글꼴·색·줄바꿈·레이아웃과 주요 상태를 비교한다. 접근성 개선과 원본 충돌은 구체적인 영향을 기록한다. 스크린샷을 본 사실과 저장·동기화를 확인한 사실을 구분한다.
