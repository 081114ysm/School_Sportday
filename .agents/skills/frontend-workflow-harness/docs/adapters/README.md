# 프로젝트별 어댑터

core는 범위·승인·증거·완료 기준을 다룬다. 아래는 실제 프로젝트에 맞춰 선택하는 내용이다. 예시가 설치만으로 프로젝트 설정이 되지는 않는다. 실행 명령은 `frontend-harness.config.json` 한 곳에서 관리한다.

| 문서 | 적용할 때 |
|---|---|
| [스택과 명령](stack.md) | 앱 최초 설정, 프레임워크·패키지 매니저 변경 |
| [디자인 원본](design-source.md) | Figma·화면 기획·기존 디자인 시스템을 사용 |
| [API와 Mock](api-mocking.md) | 서버 연동과 fixture를 검증 |
| [브라우저와 테스트](browser-testing.md) | 지원 환경·자동화·성능 예산 확정 |
| [CodeRabbit](coderabbit.md) | GitHub App 연결·자동 리뷰·현재 head 결과 확인 |
| [선택 서비스](optional-services.md) | 외부 문서·시각 회귀·리뷰 봇·배포 미리보기 |

선택하지 않은 도구를 설치·연결하거나 파일을 삭제할 필요는 없다. 사용하지 않는다고 설정·문서에 표시하고 필요한 문서만 읽는다. 원본의 Java·DB 마이그레이션 예시는 이 프론트엔드 번들에 포함하지 않는다.
