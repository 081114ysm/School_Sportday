# 선택 서비스와 외부 동작

설치 시 외부 계정이나 봇을 연결하지 않는다. 사용 중인 서비스가 실제 작업을 줄일 때 선택한다.

| 도구 유형 | 활용 | 주의할 경계 |
|---|---|---|
| Storybook / 컴포넌트 문서 | 기존 컴포넌트의 상태 재현 | 앱 여정 E2E와 실제 API 검증을 대체하지 않음 |
| 시각 회귀 서비스 | 고정 화면 차이 검토 | 개인정보·baseline 검토·비용과 실행 조건 확인 |
| 리뷰 봇 | PR diff 보조 검토 | 자체·독립 리뷰 수행 사실을 대신 기록하지 않음 |
| 배포 미리보기 | PR 환경의 인증·route·빌드 확인 | 생성 권한·공개 범위·비밀키와 테스트 계정 확인 |
| Notion / 위키 | 확정된 UI·API 명세 공유 | 머지 뒤 실제 변경 범위만, 사용자가 지시한 경우 동기화 |

외부 문서에 댓글·메시지를 남기는 동작은 읽기와 다르다. 사용자 지시 범위를 확인한다. 전송 실패나 접근 불가를 성공으로 숨기지 않는다. 로컬 산출물과 남은 작업을 보고한다.
